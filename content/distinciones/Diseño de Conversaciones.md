# Diseño de Conversaciones

## Contexto

Distinguir entre conversaciones de "posibilidad" y de "no posibilidad" es el primer paso. A partir de allí, podemos diseñar conversaciones para lograr resultados extraordinarios.

---

## Tipos de Conversaciones

1. **Conversación para posibles conversaciones:** Cuando juzgamos que no podemos sostener una determinada conversación con alguien, podemos tener una conversación acerca del hecho de que consideramos que no podemos tener esa conversación.
2. **Conversación para relación:** El resultado esperado es crear, mejorar o completar una relación. Requiere trabajar sobre el juicio de confianza.
3. **Conversación para posibilidad:** El compromiso es crear una posibilidad que no se está viendo.
4. **Conversación para oportunidad:** Crear la oportunidad conveniente.
5. **Conversación para coordinar acciones:** Implica declarar, pedir, ofrecer y prometer. Se completa cuando se escuchan promesas.
6. **Conversación para declaración y disolución de quiebres:** Declarar todo lo que impida el accionar como "quiebre" y diseñar conversaciones para accionar en coherencia.
7. **Conversación para completud:** Aquella que permite cerrar impactos emocionales limitantes (dolor, frustración, enojo), aceptar lo que no se puede modificar y accionar sobre lo que sí.

---

## Los 7 Pasos de la Comunicación Productiva

1. **Hacerme responsable de mis juicios:** “Como YO veo la situación”, "lo que me pasa con esto". (Hacer pública la Columna Izquierda de forma responsable).
2. **Hacerme responsable de TUS juicios:** “Como Tú ves la situación”.
3. **DECLARAR:** Qué queremos que pase y observar qué nos está faltando.
4. **Espacio para las OFERTAS:** “Qué estás necesitando de mí para que pase lo que queremos”.
5. **Espacio para PEDIDOS:** “Qué estoy necesitando de vos”.
6. **Escuchar aceptaciones/negociaciones:** De ofertas y pedidos.
7. **Formalización del COMPROMISO:** Hacer promesas.
